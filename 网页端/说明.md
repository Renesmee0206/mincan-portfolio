# 网页端

网站方向的东西都在这儿。**网站的实体不在这个文件夹里**，因为两个部署平台写死的路径就是根目录的
`01-网站预览/` 和 `02-网站源码/`，搬走就会发布失败——所以这个文件夹放的是它的说明和效果图。

| 在哪 | 是什么 |
| --- | --- |
| 根目录 `01-网站预览/` | **线上发布的就是这一套。** 双击 `index.html` 就能看，不用装任何东西；图片、视频、简历全在里面，可以单独拿走 |
| 根目录 `02-网站源码/` | 网站本体（React + Vite）。文字在 `src/data/site.js`，配色字号在 `src/styles/global.css`，图片视频在 `public/media/` |
| `部署手册.md` | 两个站点（GitHub Pages + 腾讯云开发 CloudBase 静态托管）怎么配、怎么更新、怎么回退，踩过的坑都记在里面 |
| `页面截图/` | 18 张页面效果图：开场 4 张 + 桌面 10 张 + 手机 4 张（桌面里含 1 张板块过场、2 张个人照片墙） |

```powershell
cd C:\Users\Renesmee\Desktop\闵灿作品集

```
